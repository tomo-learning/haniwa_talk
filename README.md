# M5StickC BLE ポン出し

M5StickC に入れた録音音声を、振動（持ち上げ検出）でランダムに再生し、M5Stack のボタン操作でも再生する。M5Stack と M5StickC は BLE で接続する。

## 構成

| パス | 内容 |
| --- | --- |
| `m5stickc_single_voice/` | M5StickC 用スケッチ。HAT-SPK から音声を再生する |
| `m5stack_voice_remote/` | M5Stack（Basic／Gray／Fire）用スケッチ。ボタンで ON/OFF と再生を指示する |
| `tools/wav_to_header.py` | WAV を再生用の `.h` に変換するスクリプト |
| `tools/test_wav_to_header.py` | 変換スクリプトの単体テスト |
| `audio_src/` | `.h` の元にした WAV |

## 必要な環境

- Arduino IDE 2 と ESP32 のボード定義（esp32 by Espressif Systems 3.3.3 でコンパイルを確認した）
- ライブラリ: M5StickC 0.3.0、NimBLE-Arduino 2.3.6、M5Unified 0.2.10、M5GFX
- M5StickC ライブラリは、依存ライブラリを入れない選択肢（英語表示では Install without dependencies）で入れてよい。依存ライブラリなしでコンパイルできることを確認した。
- ボードは、M5StickC 用スケッチでは「M5StickC」、M5Stack 用スケッチでは「M5Core」を選ぶ。
- 変換スクリプトには Python 3 と numpy が必要である。

## 動作

### M5StickC

- 起動時は ON である。
- ON の間、加速度ベクトルの大きさと 1 G の差が 0.20 G を超えると、振動によるランダム再生の対象から1つを選んで再生する。前回の検出から 1.5 秒以内は検出しない。
- `PLAY n` を受けると n 番の音声を再生する。再生中に受けた場合は、再生中の音声を止めて n 番を再生する。
- OFF の間は、振動でもポン出しでも音声を再生しない。再生中に OFF を受けた場合は再生を止める。
- `VOL n` を受けると、音量を n %（0〜100）にする。100 % は `.h` の値のまま再生する音量である。再生中に受けた場合も、その時点から新しい音量で再生する。音量はフラッシュ（NVS）に保存し、次に起動したときも同じ音量で始める。

### M5Stack

- 起動すると M5StickC を探して接続する。スキャンは1回 10 秒で、見つからなければ繰り返す。接続が切れたら探し直す。
- 通常の画面では、ボタン A の短押しで ON/OFF を切り替え、ボタン B で次の音声を選び（最後の次は最初に戻る）、ボタン C で選んでいる音声を再生する。A の切り替えは、長押しと区別するため、ボタンを離したときに行う。M5StickC の状態をまだ受け取っていないときは、A を押すと状態を要求する。
- A を 0.8 秒押し続けると音量画面を開く。音量画面では、B で 10 % 下げ、C で 10 % 上げ、A の短押しで通常の画面に戻る。
- 画面の1行目には、接続の状態を「M5StickC を探しています」「M5StickC への接続を試みています」「M5StickC に接続済み」のいずれかで表示する。接続済みのときは、右端に「A長押し: 音量」と表示する。その下に ON/OFF と音量、音声の一覧を表示する。一覧では、選んでいる音声の行の色を反転し、再生中の音声に「再生中」と表示する。
- 接続の直後に状態と一覧を要求する。受け取れなかった場合は、状態は 1 秒ごと、一覧は 3 秒ごとに要求し直す。
- 表示できる音声は 32 個までである（`MAX_VOICES`）。通知は 128 バイトまで受け取るので、音声の名前は UTF-8 で 120 バイト（日本語で 40 文字）以内にする。

## BLE の取り決め

M5StickC はデバイス名 `M5StickC` で広告（接続を待っていることを周囲に知らせる送信）を行い、接続を待つ。M5Stack は、下のサービス UUID を広告している機器に接続する。データのやり取りには、キャラクタリスティック（BLE で読み書きするデータの単位）を2つ使う。

| 項目 | UUID | 属性 |
| --- | --- | --- |
| サービス | `3d436b81-f335-4abf-9169-7b95a4d4df16` | |
| コマンド用キャラクタリスティック | `07abb273-12ef-45ba-879c-2011ecf81e38` | 書き込み（応答あり・応答なし） |
| 通知用キャラクタリスティック | `da3650aa-5da4-4cac-8ed5-fcdb0b15eb66` | 読み出し・通知 |

コマンドは UTF-8 の文字列で、1回の書き込みで1つ送る。大文字と小文字は区別しない。

| コマンド | 動作 |
| --- | --- |
| `ON` または `1` | ON にする |
| `OFF` または `0` | OFF にする。再生中なら再生を止める |
| `STATUS` | 状態（`STATE`）と音量（`VOL`）を通知する |
| `PLAY n` | n 番の音声を再生する（n は 0 から数える） |
| `VOL n` | 音量を n %（0〜100）にする |
| `LIST` | 音声の数と名前を通知する |

通知も UTF-8 の文字列である。

| 通知 | 意味 |
| --- | --- |
| `STATE ON -1` | ON で、再生していない |
| `STATE ON 3` | ON で、3 番を再生している |
| `STATE OFF -1` | OFF である |
| `VOL 80` | 音量が 80 % である（`VOL` と `STATUS` への応答） |
| `COUNT k` | 音声が k 個ある（`LIST` への応答の最初の通知） |
| `NAME i 名前` | i 番の音声の名前（`LIST` への応答） |
| `ERR 内容` | 受け付けなかったコマンド |

M5StickC は、状態が変わるたびに `STATE` を通知する。通知用キャラクタリスティックを読み出すと、最後に通知した文字列が返る。スマホの BLE アプリ（nRF Connect など）からも、コマンド用キャラクタリスティックに文字列を書き込めば操作できる。

## 音声一覧

| 番号 | 名前 | ファイル | 声 | 振動によるランダム再生 |
| --- | --- | --- | --- | --- |
| 番号 | 名前 | ファイル | 元の WAV | 声 | 振動によるランダム再生 |
| --- | --- | --- | --- | --- | --- |
| 0 | voice | `voice.h` | `voice_original.wav` の 1.18〜2.25 秒 | 人の声 | 対象 |
| 1 | hello | `hello.h` | `hello_original.wav` | ずんだもん | 対象 |
| 2 | please stay here | `please_stay_here_16k.h` | `please_stay_here_original.wav` | ずんだもん | 対象 |
| 3 | do research | `do_research_16k.h` | `do_research_original.wav` | ずんだもん | 対象 |
| 4 | stay clean | `stay_clean_16k.h` | `stay_clean_original.wav` | ずんだもん | 対象 |
| 5 | 人間に戻して | `zunda_01.h` | `zunda_01.wav` | ずんだもん | 対象 |
| 6 | 今日も会えて嬉しいよ | `zunda_02.h` | `zunda_02.wav` | ずんだもん | 対象 |
| 7 | 今日も頑張ろう！ | `zunda_03.h` | `zunda_03.wav` | ずんだもん | 対象 |

音声は 16 kHz・8 bit（符号なし、無音は 128）の PCM で、`.h` の配列としてフラッシュに置く。元のスケッチで `#include` していた `hello_granpa.h` は外した。

すべての音声は、最大振幅を ±124 に合わせた（ピーク正規化）。0 番以外は前後の無音も削った。これにより、元のスケッチの音声と比べて音量は 2.7〜11.2 dB 上がり（計算値）、1〜4 番の声の始まりまでの時間は 0.09〜0.25 秒短くなった。

`*_original.wav` は、元のスケッチの `.h` の値をそのまま WAV にしたものである（16 kHz・8 bit）。1〜4 番の元の `.h` は、無音の値が 127 であった。

5〜7 番は、2026-09-29 にずんだサイトの非公式版 WEB版VOICEVOX（ずんだもん・ノーマル）で合成し、tts.quest の配信サーバーから WAV（24 kHz・16 bit）で取得した。

## 音声の追加手順

1. WAV を `audio_src/` に置く。
2. 次のコマンドで `.h` に変換する。前後の無音を削り、最大振幅を ±124 に合わせ、両端に 10 ms のフェードを付ける。

   ```bash
   python3 tools/wav_to_header.py audio_src/xxx.wav m5stickc_single_voice/xxx.h --name xxx
   ```

   入力できるのは 8 bit または 16 bit の整数 PCM の WAV である。オプションは次のとおりである。

   | オプション | 動作 |
   | --- | --- |
   | `--start 秒` `--end 秒` | 指定した区間だけを切り出す |
   | `--no-trim` | 前後の無音を削らない |
   | `--no-normalize` | 最大振幅を合わせない |

3. `m5stickc_single_voice.ino` に `#include "xxx.h"` を足し、`voices[]` に1行足す。振動によるランダム再生の対象にするかは、その行の最後の値（`true` / `false`）で決める。
4. M5StickC に書き込む。M5Stack は接続時に一覧を受け取るので、音声が 32 個以内であれば M5Stack 用スケッチの書き換えは要らない。

変換スクリプトの単体テストは `python3 -m unittest discover -s tools -v` で実行する。

## 実機での確認手順

1. M5StickC と M5Stack の電源を入れ、M5Stack の画面に「M5StickC に接続済み」と音声の一覧が表示されることを確かめる。
2. M5StickC を持ち上げ、振動によるランダム再生の対象の音声が鳴ることを確かめる。
3. M5Stack の B で音声を選び、C で選んだ音声が鳴ることを確かめる。
4. 再生中に別の音声を選んで C を押し、再生中の音声が止まって選んだ音声が鳴ることを確かめる。
5. A を押して OFF にし、持ち上げても C を押しても鳴らないことを確かめる。再生中に A を押し、再生が止まることも確かめる。
6. A を押して ON に戻し、持ち上げると鳴ることを確かめる。
7. A を 0.8 秒押し続けて音量画面を開き、B と C で音量が 10 % ずつ変わることを、再生して確かめる。A で通常の画面に戻る。
8. M5StickC の電源を入れ直し、M5Stack が接続し直すことと、音量が電源を切る前の値のままであることを確かめる。

## クレジット表記

ずんだもんの音声は VOICEVOX で生成した。音声を使うときは「VOICEVOX:ずんだもん」と表記する。
